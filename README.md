# Sobre mí

Estudiante de 8vo ciclo de Ingeniería Informática, de 20 años, con 1 año de experiencia en desarrollo web. Tengo conocimientos en Machine Learning con Python y bases de datos no relacionales, además de formación en sistemas embebidos y bases en diseño electrónico y modelado 3D. Mi enfoque es integrar hardware y software para crear soluciones de IoT y sistemas inteligentes.
